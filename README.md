# DevOps Git Final Project

This repository represents a small operations project used to practice
real-world Git and GitHub workflows.

## Project Components

- Application configuration
- Monitoring configuration
- Logging configuration
- Operational PowerShell scripts
- Deployment documentation

## Repository Structure

- `config/` - Application and service configuration
- `scripts/` - Operational helper scripts
- `docs/` - Deployment and operations documentation

## Goal

Maintain the project using a clean Git workflow while investigating,
developing, reviewing, and recovering changes safely.
